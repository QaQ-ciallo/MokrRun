## 4. 关键否定证据：模块从未收到「开始」

对全量日志（`C:\mokrlogs\logcat-full.txt`）逐关键字统计（截至 07:18）：

| 关键字 | 命中数 | 说明 |
|---|---|---|
| `config via`（Intent 配置通道） | 0 | 浮窗「开始」未触发 launchTargetWithConfig |
| `command mode=`（广播命令） | 0 | 未发送结束/暂停/继续 |
| `mode set to` | 0 | 引擎状态从未被命令改变 |
| `applied from intent` | 0 | 从未应用配置 |
| `tick dist=` | 0 | 引擎从未进入运行态（mode=1） |

结论：用户按的是**目标应用自己的开始按钮**，被应用的反模拟定位闸门拦下；
模块侧浮窗仍是「就绪 · 待开始」，本轮跑步根本没有开始。
